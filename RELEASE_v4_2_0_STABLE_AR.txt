منصة آلين — v4.2.0 Stable
تاريخ التجميد: 2026-08-12

الأساس المعتمد:
- مبنية مباشرة من RC24 Staff Realtime Centralized بعد نجاح الفحص.
- لا توجد إضافة وظائف جديدة في Stable؛ تم تثبيت الإصدار وتنظيف تسميات RC فقط.

الثوابت المعتمدة:
1) المتجر العام/الطالب لا يفتح اتصال Realtime دائم.
2) Realtime مخصص لأدوار الموظفين عبر Channel مركزي واحد لكل جلسة موظف.
3) جرس الطلبات لا ينشئ Channel مستقل.
4) Service Worker دورة حياة فقط ولا يعترض HTML/CSS/JS/الصور ولا ينشئ Runtime Cache.
5) Stable ينفذ تنظيف CacheStorage/Service Worker قديم مرة واحدة عند الانتقال من إصدارات RC، بدون مسح السلة أو الحساب أو اللغة أو الوضع أو بيانات IndexedDB.
6) سبلاش الموبايل/الآيباد يبقى حسب النسخة المعتمدة ولا تم تغيير منطق السرعة.
7) لا يوجد تغيير على Supabase أو مخطط قاعدة البيانات في تحويل RC24 إلى Stable.

فحص الإصدار:
- VERSION = 4.2.0
- 145 Action مكتملة

- Audit الرسمي: OK

- SQL جديد مطلوب: لا

ملاحظة أمنية تشغيلية:
تجميد Stable لا يعني اختفاء Advisories الخاصة بالبنية الخلفية. تبقى مراجعة Supabase Security Advisor مهمة قبل/بعد أي DDL مستقبلي، ولا يجوز تغيير صلاحيات SECURITY DEFINER عشوائياً لأن بعض الوظائف العامة مقصودة وتتحقق من المدخلات/الدور داخل الخادم.

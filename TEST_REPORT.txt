منصة آلين v4.1.2 — إصلاح تحويل الطلب للمندوب

التعديل المنفذ:
- إصلاح ظهور «تعذر تحديث الطلب» عند تحويل مهمة إلى المندوب.
- دعم قاعدة Supabase الجديدة عبر RPC الرسمي.
- توافق تلقائي مع خدمة التعيين القديمة إذا كانت موجودة.
- مسار احتياطي محدود للإدارة لتحديث التعيين عند اختلاف بنية المشروع القديم.
- توحيد معرّف المندوب بين accounts وcouriers في المشاريع القديمة.
- تحديث حزم الكمبيوتر والموبايل وكاش PWA إلى 4.1.2.
- لا توجد ملفات CMD أو PowerShell داخل النسخة.
- لا يحتاج هذا الإصلاح إلى تشغيل SQL حتى يعمل مسار التوافق.

الفحوصات المنفذة محلياً:
- JavaScript syntax: نجح لملف خدمة المندوب وحزم الكمبيوتر والموبايل.
- مسار قاعدة جديدة (RPC): نجح بمحاكاة الخادم.
- مسار الخدمة القديمة (Edge Function): نجح بمحاكاة الخادم.
- المسار الاحتياطي المباشر للإدارة: نجح بمحاكاة الخادم.
- التحقق من إدراج الإصلاح داخل حزم الكمبيوتر والموبايل: نجح.
- التحقق من عدم وجود CMD أو PS1: نجح.

مهم:
- لم يتم تنفيذ أي SQL على قاعدة المستخدم.
- لم يتم رفع الملفات إلى GitHub.
- الفحص أعلاه محلي ومحاكى، وليس اختباراً مباشراً على مشروع Supabase الحي.

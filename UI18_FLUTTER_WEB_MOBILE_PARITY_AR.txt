منصة آلين — UI18 Flutter Web-Mobile Parity
============================================

هذا الإصدار يبقي ملفات الويب كما هي، ويطوّر تطبيق Flutter ليأخذ تفاصيل واجهة الويب للموبايل:

1) البنرات:
- دوران تلقائي كل 6.5 ثانية مثل الويب.
- صورة الإعلان في الأعلى، وعبارة الإعلان/العنوان والوصف أسفل الصورة.
- البنرات تبقى مربوطة ببيانات Supabase نفسها.

2) الأقسام:
- استخدام صور الأقسام المرفوعة من إعدادات المنصة نفسها:
  store_category_icon_booklet / stationery / gift / deal.
- إضافة قسم العروض عند وجود منتجات مخفّضة.

3) الصفحة الرئيسية:
- بحث + بنرات + أقسام مصورة + رفوف عروض ومختارات وملازم ومنتجات جديدة.
- التنقل السفلي يبقى بدلاً من NavigationRail.

4) خيارات الطالب:
- الحساب/تسجيل الدخول والطلبات والعروض الخاصة.
- اللغة: العربية / کوردی / English مع حفظ الاختيار.
- المظهر: نهاري / ليلي مع حفظ الاختيار وتطبيق Theme على التطبيق.
- تواصل معنا: يعتمد contact_text / whatsapp / روابط الشبكات من إعدادات Supabase.
- حول منصة آلين: يعتمد about_title / about_text من إعدادات Supabase.

5) البناء:
- Flutter version: 5.1.0+3
- GitHub Action: Build Alin Flutter Android UI18
- اسم الـArtifact الجديد: alin-flutter-ui18-v5.1.0-build3

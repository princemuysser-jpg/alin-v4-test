منصة آلين — إصلاح معاينة وصولات التسويات
===========================================

الأساس: 4.1.5-tracking-receipts-2
الإصدار: 4.1.5-tracking-receipts-3

الإصلاح:
- إصلاح زر معاينة وصل التسوية عندما لا يحتوي سجل التسوية على id أو receipt_number.
- إنشاء مفتاح ثابت بديل من نوع الحساب والحساب والتاريخ والمبلغ وطريقة التسوية.
- دعم الحقول البديلة settlement_id وtransaction_id وpayout_id.
- دعم مبالغ paid_amount وsettled_amount وvalue وtotal.
- دعم تواريخ date وsettled_at وطريقة الدفع method.
- إضافة payouts وfinance_payouts إلى مصادر التسويات عند توفرها.
- لم يتم تعديل SQL أو بيانات Supabase.

الفحص:
- فحص صياغة JavaScript نجح.
- اختبار منطقي لثلاث حالات تسوية، منها سجل بدون أي رقم داخلي، نجح.
- لم يكتمل اختبار Chromium الكامل لأن عملية Chromium لم تنته داخل بيئة الفحص.

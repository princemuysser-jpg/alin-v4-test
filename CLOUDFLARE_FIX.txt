ALIN v4.1.5.2 - Cloudflare Pages route fix

The desktop and mobile entry pages now use conflict-free directory routes:
  /app-desktop/
  /app-mobile/

Each route contains its own index.html and uses a root base URL for assets.
This avoids the Cloudflare Pages redirect loop affecting the former
store-desktop.html and store-mobile.html files, even if those old files
remain in the connected GitHub repository.
